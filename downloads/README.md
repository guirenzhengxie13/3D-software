# 官方安装包

`scripts/download-official.ps1` 从 Revopoint 官方下载中心列出的地址获取 Revo Scan 6 Windows 安装包和 RANGE 2 中文指南，并生成 SHA256 与 Windows 签名检查记录 `manifest.json`。

这些文件仅下载，不自动运行安装。Revo Scan 用于设备连接、标定检查和导出测试数据；安装 Revo Scan 并不等于取得第三方实时点云接口。SDK 及授权需要另行申请。

来源：https://www.revopoint3d.com/pages/support-download （核对日期：2026-10-15）。后续版本以官方页面为准。SHA256 是本次下载的本地完整性记录，不代表已与厂商公布的校验值交叉核验。
