# 原帧、ROI与融合参数草稿

2026-10-25。工程工作区 → 对应点 → 展开“下一步：绑定原帧并重融合”。现在可以保存未完成的原帧归属、依据、ROI和融合参数；之后恢复继续编辑。它与选点草稿、模型结果版本分别保存。

## 使用方法

1. 选择已核验对齐和具体候选，按原帧ID或从1开始的保存序号填写两片段范围。未写完的范围、空白依据、部分ROI也可先保存。
2. 展开“保存未完成的帧编辑”，填写名称，点击“保存帧编辑草稿”。每次另存独立快照，旧记录保留；当前不是自动保存。
3. 从列表选择后明确点击恢复。服务核对索引、对齐摘要、原会话与模型来源。恢复会取消旧预设引用、坐标确认和已核验状态；不会自动开始任务。
4. 补完帧范围和六个ROI边界，重新确认两模型保留原保存扫描毫米坐标，再点击“核验原帧与输入版本”。此时才实际读取选中深度与优化位姿、解析范围、验证参数并生成固定计划。
5. 审阅核验的帧数、实际原ID和参数，明确点击“按此核验运行两组重融合”。编辑任何参数也会使旧核验失效。

“导出草稿 JSON”可携带未完成表单。“载入草稿 JSON”会先在后端核对当前工程和对齐来源；它不会创建保存快照或可执行核验。需要保留到项目时再点击保存。

若请求保存期间继续编辑，保存的是请求发出时的表单，页面提示后续内容尚未保存。恢复或文件读取期间输入发生变化，旧回复不覆盖新编辑。切换工程后的旧回复同样会被丢弃。

## 四项融合参数

| 参数 | 默认 | 当前支持范围 |
| --- | ---: | --- |
| 体素 voxel_mm | 0.6mm | 0.3–3mm |
| 截断 truncation_mm | 2.4mm | 0.6–12mm，且为体素2–8倍 |
| 深度跳变 edge_threshold_mm | 3mm | 0.5–10mm |
| 提取权重 weight_threshold | 3 | 1–20 |

这些是当前工程工具的支持范围，不是最佳参数或物理精度保证。较细体素会增加计算量，截断和权重也会改变表面。两组共享同一份已核验计划中的参数；执行接口不接受临时覆盖。旧计划没有参数字段时仍用原默认值。

参数进入 `fragment-plan.json`，计划SHA固定到核验记录。服务还核对核验记录与计划中的参数一致；工作流和每组最终摘要保留实际参数。默认CLI仍兼容旧计划，没有添加任意脚本或命令入口。运行时若计划在初次hash与读取之间变化，也会在提交/执行前拒绝。

## 草稿结构与边界

```text
format: fragment-editor-draft
format_version: 1
unit: mm
alignment: {relative_path, sha256} 或 null
candidate / mode: 对齐候选及原帧ID/保存序号方式
source_frames / target_frames: 原始文本，保留大整数与未完成范围
source_basis / target_basis / decision: 原始文本
roi_fields: 六个边界文本，可部分为空
fusion_fields: 四个参数文本，可尚未写完
```

文本草稿可以包含未完成或错误想法，保存不表示帧选择有效。它不含坐标确认、核验ID、计划、任务ID或变换矩阵，也不证明物理对应正确。不能把界面PLY顶点编号当原帧编号。

每份快照另记录工程索引SHA、名称、UTC时间及对齐摘要/会话/原模型/原候选的来源SHA。**保存与恢复不解码深度，不固定每帧深度和位姿版本**；后续显式核验才检查实际载荷并将其固定到计划。缺深度、缺优化位姿或损坏载荷仍会阻止执行。

状态在 `reports/web-studio/frame-drafts/<扫描ID摘要>/state.json`，使用OS锁、预期状态SHA和原子替换；旧页面及另一服务的过期保存会被拒绝。损坏状态保留原字节，不自动清空。旧路径只在内存映射；对齐身份采用工作区相对路径与摘要SHA，适应已支持的跨电脑根路径映射。

Git仅同步代码和精简证据。迁移实际草稿需连同原工程索引、对齐摘要/会话、原模型与来源文件一起保留字节，并保持各电脑自己的本地路径配置。共享网络目录的跨电脑锁行为仍未实测。

这不是完整编辑器撤销系统。模型版本保留1至3份结果组合，选点草稿保留PLY原顶点对，帧编辑草稿保留本表单；三者都不会自动接受几何候选。

## 接口与复现

- `GET /api/frame-drafts?scan=<ID>`：列表、当前索引与状态SHA、可用性。
- `GET /api/frame-drafts?scan=<ID>&draft_id=<ID>&index_sha256=<SHA>`：核对来源后恢复内容。
- `POST /api/frame-drafts`：scan_id、index_sha256、state_sha256、label、draft；返回201。
- `POST /api/frame-drafts/inspect`：scan_id、index_sha256、draft；检查便携草稿但不保存或生成核验。
