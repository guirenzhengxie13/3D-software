# 扫描数据包准备说明

当前希望先拿到两台设备已生成的完整原生工程，检查格式；之后再获取同一个物体的多次独立扫描，验证交互式组合重建。

## 可以直接转给采集者的说明

请保留扫描软件能重新打开的完整原生工程，保持目录和文件名层级，整个工程打包发送。仅提供最终 STL / OBJ / PLY 不足以研究逐帧数据；也请另外导出一份官方融合结果，方便我们对照。

请简单记录：设备型号、扫描软件完整版本、物体名称、扫描次数/方向、是否用了转台，以及这份工程是否已经融合或编辑。如果已有失跟、重影或多包对不齐的问题，请截图或注明出现的位置。

后续对同一个物体做多次扫描时，各次保留部分共同可见区域，同时覆盖不同侧面；每次作为独立工程保存。物体本体应保持相同形状。扫描完成后，在人工删帧和裁剪前保留一份完整副本；已经处理过的现有工程也可以先提供，但请说明处理状态，不需要为凑“原始数据”自行改动文件。

## 接收后的检查

- 确认每份工程对应的设备、物体与扫描次数；不同物体的工程仅用于分别解析，不相互融合。
- 清点实际深度、标定、位姿、颜色、处理结果等资源，记录缺失项和格式识别状态。
- 抽查少量已存帧的形状、尺度、方向以及与官方预览的对应关系。
- 保留原件，解析和实验使用副本；确认工程全部保存完成后再复制，避免混入正在写入的文件。

不要求先取得 SDK，也不要求先处理成漂亮模型。凌乱但完整、可重开的工程和具体失败案例，正适合用来验证本课题的软件。
