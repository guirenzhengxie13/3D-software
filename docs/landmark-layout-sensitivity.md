# 选点布局与整体变换敏感性

工作台目前已经拒绝近共线选点，并显示选点RMSE、最大残差及尺度比。继续研究发现：即使两组都不近共线、选点残差相近，覆盖范围很小的一组仍可能对整体变换更敏感。

## 本次控制条件

使用失败杯子片段0的既有训练PLY，共13206点。两种布局各4个实际PLY顶点：

- 分散布局：在完整训练点集上做确定性的最远点选择；ID为 `12581,1125,4216,10056`。
- 局部布局：取接近全云均值的原点附近16个邻居，再做同样的4点选择；ID为 `2203,4375,6056,7488`。

这些是PLY原顶点ID，不是扫描帧ID。它们没有被认定为人工可辨认的物理对应位置。

真实变换人为定义为单位阵。源选点保持不变，目标坐标为同一选点加独立Gaussian扰动，假设σ为0.1、0.2、0.5mm。固定种子20261023和同一256×4×3的标准扰动数组，两个布局与三档σ使用相同随机数，避免挑选有利试验。零扰动时先在所有源点上核对单位变换。

每次用现有刚体拟合器求变换，记录：

1. 选点拟合RMSE：变换后的4个源点到带扰动目标坐标的均方根距离。
2. 全云已知真值位移：将估计变换作用于全部原点，和单位真值下**同一个原点**比较，再计算RMS。没有做最近邻匹配。

三档、两布局、每组256次，共1536次合成拟合，不是1536次扫描，也不是1536项单元测试。

## 结果与解释

假设σ=0.2mm时，分散/局部布局的选点RMSE中位数约0.232/0.231mm；全云位移中位数却约0.201/3.089mm，P90约0.296/4.963mm。局部布局的全云中位位移约大15.4倍。

两组选点RMS覆盖半径约58.91/1.96mm；第二/第一方差比约0.916/0.712，都远高于现有1e-6的不共线检查线。这个受控反例提示：形状不退化和覆盖范围足够大是不同信息。仅显示拟合残差不能解释整个物体上的变换敏感性。

区分选点拟合误差与目标位置误差的基础研究可参考[Fitzpatrick、West和Maurer](https://pubmed.ncbi.nlm.nih.gov/9874293/)。这里是本项目自己的数值控制，没有复现其完整误差预测公式，也没有把假设σ校准为设备或人的实际误差。

本研究没有改变现有选点门槛或替用户确定物理对应。下一步值得在工作台显示选点的实际RMS覆盖半径、相对物体跨度和来源，同时继续回查原深度；不将一次合成试验中的数值作为通用接受阈值。
