# 未完成的对应点草稿

2026-10-24。进入工程工作区的“对应点”模式，选择已建立的工作区。现在不足三对、尚未计算、计算后又修改、以及只选了固定点等待配对的状态，都可以保存。恢复草稿不会自动运行配准或融合。

## 使用方法

1. 在左侧固定片段选一点，再在中间移动片段选同一物理位置。未选完也可以先停下。
2. 在“未完成的选点草稿”填写名称，点击“保存草稿到本项目”。每次保存产生独立快照，旧草稿保留。当前没有自动保存；关闭页面前需要明确点击保存。
3. 下次打开同一个工作区，刷新草稿列表，选择后点击“恢复所选草稿”。保存时尚未配对的固定点也会恢复，可以继续在移动片段点选。
4. 如果草稿来自手动对齐或已修改的手动选点，恢复后先显示该工作区的位置候选，并明确要求重新计算。原拟合矩阵不存入草稿，不把旧结果当成新选点的结果。至少三对并通过既有非共线检查后，才计算；另存模型仍需明确提交。
5. “导出草稿 JSON”可以携带未完成选点。用“载入选点或草稿 JSON”恢复。独立HTML文件可导出JSON；项目内保存需要从本地HTTP工作台打开。

保存的是请求发出时的选点。如果等待保存期间继续点选，页面会提示后续编辑尚未保存。等待恢复或文件载入期间若当前选点变化，旧回复不会覆盖新编辑，需再次明确恢复。

## 草稿保存什么

```text
format: reconstruction-landmark-draft
format_version: 1
unit: mm
source / target: 模型SHA、固定或移动片段编号
candidate_label / candidate_sha256: 所选位置候选及原候选文件版本
requires_recompute: 手动选点是否需重新计算
point_pairs: [{target: {id, xyz}, source: {id, xyz}}, ...]
pending_target: {id, xyz} 或 null
```

`id`是原PLY顶点编号，不是帧ID，也不是显示点的行号。草稿最多64对。服务端验证页面载荷、原PLY顶点、浮点预览坐标及完整模型SHA，允许暂时错误或不够数量的对应关系作为草稿想法，但不把它们认定为可信配准。

每份本地快照另记录名称、UTC时间、原工作区HTML字节SHA和输入文件SHA。网页内预览、模型内容、方向/片段身份或候选换版会阻止错误恢复；程序不修改旧SHA使新文件通过。便携JSON不绑定HTML字节，但仍要求模型、方向、候选来源和所需原顶点一致；预览不含所需顶点时会拒绝，可用已有 `--include-session` 原编号保留机制重新建立预览。

草稿**不包含拟合矩阵、相机视角、显示增亮、原帧归属、ROI或算法参数**。工程结果版本仍保存模型组合与来源，两种记录独立；当前还不是完整编辑器撤销系统。

## 文件与迁移

本地状态位于 `reports/web-studio/landmark-drafts/<工作区相对路径摘要>/state.json`。更新有预期状态SHA、跨进程OS锁及原子替换；旧页面或另一服务先保存后，过期请求会被拒绝，刷新列表再明确另存。首次创建锁时先获得锁再初始化，修复Windows并发创建时可能的写锁竞争。

通过HTTP打开旧生成页面时，服务在内存使用当前编辑器与旧内嵌数据组成响应，并附原HTML版本。**磁盘上的历史HTML不重写**，已有计划、模型和页面SHA保持不变。直接打开历史file页面仍可能看到旧界面；请从工作台进入。

迁移需要同时保留工作区HTML、原模型、候选文件与完整草稿目录，保持字节不变。状态目录使用工作区相对路径，旧绝对输入路径通过现有映射只在内存解析。新克隆的Git仓库没有忽略目录中的这些本机数据；独立电脑代码同步不等于草稿同步。共享网络目录的跨电脑并发没有实机测试。

## 选点覆盖提示

选择至少两对后，页面显示固定、移动各自的**选点RMS半径**：每个选点到选点质心距离平方的平均值再开方，单位毫米。旁边比例以当前显示预览云RMS半径为分母，预览范围变化会影响比例，不等同完整模型覆盖。

它帮助识别选点集中问题，不是精度、置信度或新的接受门槛。刚体拟合器与非共线门槛未改变。此前[合成扰动研究](landmark-layout-sensitivity.md)显示，局部选点即使残差很小，也可能产生较大的远端运动。

## 接口与验证

- `GET /api/landmark-drafts?workbench=<ID>`：草稿列表、页面和状态SHA、可用性。
- `GET /api/landmark-drafts?workbench=<ID>&draft_id=<ID>&page_sha256=<SHA>`：按原模型及原顶点核对后读回所选草稿。
- `POST /api/landmark-drafts`：`workbench_id`、`page_sha256`、`state_sha256`、`label`、`draft`。成功为201；不接收任务命令或变换。
