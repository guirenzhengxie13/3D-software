# 片段连接的局部几何约束诊断

本工具回答的是：**在当前这批最近邻对应关系附近，哪些小幅运动较难被点到平面残差区分？** 它不判断这些对应关系是否真实，也不输出物理位姿不确定度。

## 计算约定

将移动片段变换后的训练点记作 `p`，其最近目标点记作 `q`，目标单位法线为 `n`。残差为 `n·(p−q)`。以目标训练点的均值 `c` 为旋转中心，目标点相对中心的RMS半径为固定长度 `L`。两个候选使用相同的 `c` 和 `L`。

对小运动 `a=[旋转弧度XYZ, 平移毫米XYZ/L]`，归一化残差的一阶变化是 `J·a`，其中：

```text
J = [ ((p − c) / L) × n , n ]
H = (Jᵀ J) / 对应数
```

计算H的6个特征值和方向，除以最大特征值展示相对谱。每个方向包含旋转与平移，不能直接解释为某一轴的毫米误差。法线正反号不会改变H。平均化避免仅复制同一批点就放大矩阵数值，但没有消除真实扫描观测的相关性。

单平面理论上缺3个一阶约束方向；理想球面缺3个旋转约束方向；不含端盖的理想圆柱缺沿轴平移和绕轴旋转约束。新增测试使用这些已知不变性，同时用微小刚体扰动验证导数，测试坐标旋转/平移和毫米→米不改变归一化谱。

这个局部诊断借鉴[Zhang、Kaess、Singh的退化分析思路](https://www.cs.cmu.edu/~kaess/pub/Zhang16icra.html)，这里给出了本项目自己的完整归一化与筛选定义；没有声称复现论文中的完整估计器或阈值。

## 真实输入与筛选

当前研究固定失败杯子 `scan_20261018131222` 的8份训练PLY和7条原有候选。保留文件中的训练法线，只做单位化，不重新拟合候选或法线。索引、研究来源、图摘要、旧预留摘要和代码共17份文件记录SHA，结束时重新核对相同版本。

分别检查1.5、3、6mm最近邻距离，以及源/目标法线绝对夹角≤30°。每条连接保留原保存关系和冻结几何候选，显示前向谱、双向距离覆盖、对应数量和唯一目标点数。

“相同源点”只保留两种关系都通过筛选的原源点行号；两个候选的目标最近邻和法线仍可能不同。因此它减少了选择集合变化造成的混淆，不能变成完全同对应的独立精度验证。

阈值、法线、旋转中心和长度的定义都影响谱；1%只是显示参考线，不是接受门槛。局部谱没有搜索所有可能对齐，不能识别全局对称多解。单一数值较好时，仍可能对齐到错误的杯壁或片段位置。

## 对交互流程的意义

局部残差、约束强度和双向覆盖用于解释候选行为；原深度支持/自由空间冲突用于回查与保存观测的相容性。二者都依赖同源数据和已有处理选择，不等于物理真值。

例如3→2在3mm条件下有90.7%/76.0%双向距离覆盖，局部点到平面RMS约0.212mm，但之前的预留2mm重复冲突仍为31.9%。5→4局部比值约2.99%，在相同源点上却仅0.58%，之前预留支持仅2.34%。预留分母包含未定/遮挡、视图数量不一，支持和冲突可重叠；这些比例不能当成正确率。

下一步值得做的是让用户在这些连接上指定可辨认的同一物理位置，再走已接通的“核验对齐→明确原帧→两组重融合”链路。当前不把局部特征向量直接变成补扫相机方向，也不让Agent用它单独决定接受或删除片段。
