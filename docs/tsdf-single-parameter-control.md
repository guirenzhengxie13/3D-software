# 固定原帧的体素与截断单参数对照

在完成[实际体素追踪](tsdf-voxel-evidence.md)后，补齐0.6/0.8mm体素与2.4/3.2mm截断的四种组合。这样能固定其中一项，只改变另一项，分清先前两项共同变化的影响。

全部使用失败杯子同一114条保存记录、相同ROI像素、相同每组应用位姿、3mm深度跳变与提取权重门槛3；没有重新配准或增加采集。每组229份原深度/优化位姿/索引SHA和位姿数组逐项相同。旧两组已经用当前核心代码的只读回放复现完整点集，新两组核对实际卷尺寸与核验计划一致。

## 四组的完整点数

| 位姿 | 体素 | 截断2.4mm | 截断3.2mm | 只增大截断的点数差 |
| --- | --- | ---: | ---: | ---: |
| 原保存位姿 | 0.6mm | 67,226 | 67,418 | +192 |
| 原保存位姿 | 0.8mm | 37,663 | 37,762 | +99 |
| 冻结片段校正 | 0.6mm | 66,376 | 66,506 | +130 |
| 冻结片段校正 | 0.8mm | 37,088 | 37,186 | +98 |

在这份局部组件与这段参数范围内，体素0.6→0.8mm使输出点数减少约44%；固定体素、截断2.4→3.2mm使点数增加约0.2–0.3%。点数受采样密度与提取影响，不能据此判断谁更准确。单改截断的表面差异最大仍可到约2.84mm，所以总点数变化小也不能当作局部几何完全不变。

## 极端差异位置的结论更明确了

原保存位姿的粗参考点#27957，先前离细点集最近约20.724mm：

| 当前配置 | 该固定参考XYZ到完整点集的最近距离 |
| --- | ---: |
| 0.6mm体素 / 2.4mm截断 | 20.72354mm |
| 0.6mm体素 / 3.2mm截断 | 20.72354mm |
| 0.8mm体素 / 2.4mm截断 | 0mm |
| 0.8mm体素 / 3.2mm截断 | 0mm |

因此在本次测试范围内，这个位置的出现/缺失随体素网格变化，增大截断没有补回细网格该处表面。结合前一阶段实际体素读数，可以定位旧两组的直接提取差异来自局部严格权重条件。新两组没有额外逐帧体素回放，不能把旧的全部体素数值套到新截断上。

校正细点#50670在两种0.6mm配置都保留相同坐标；到0.8mm点集的最近距离则随截断从8.684mm变为7.939mm。这也说明不能把所有局部变化都简化成单一因素。

上面的0mm表示参考坐标恰好存在于派生点集，不是物理误差为0。最近点编号各自属于各自模型，不能作为跨模型真实对应。这些扫描已用于探索，全部114帧进入融合，没有独立留出真值；其它222条保存记录仍未加入，整份失败扫描未修复。

## 实现与复现

- `scripts/analyze_tsdf_parameter_factorial.py`：固定312份输入/代码，核验原帧/ROI/位姿/参数，逐边要求恰好改变一项，计算全点双向距离并生成8份共享查看器页面。
- `web/studio/tsdf_parameter_factorial.html`：4组点数矩阵、8组可切换单参数对照及固定XYZ检查。
- `tests/check_tsdf_factorial.cjs`：执行实际生成控制器，检查8种选择、8份查看器、32段内嵌脚本及761,996个预览原顶点的坐标/编号；额外核对HTTP返回字节一致。测试用模拟DOM，没有新增浏览器画面证据。
