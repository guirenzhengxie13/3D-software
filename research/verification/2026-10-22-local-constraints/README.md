# 失败杯子局部约束诊断：2026-10-22

对8份已冻结训练片段、7条已有连接计算局部点到平面约束，未重拟合、修改门槛或融合新模型。17份来源/代码文件被固定SHA；原训练法线只归一化。

新发现是：局部数值稳定性不足以挑出正确连接。5→4候选的局部比值2.99%，比某些训练通过连接更高，但原预留支持仅2.34%；限制为两种关系共同匹配的相同源点后，比值降到0.58%。6→5也从1.99%变为0.48%。3→2虽有90.7%/76.0%距离覆盖和0.212mm局部点到平面RMS，之前的预留深度仍有31.9%重复自由空间冲突。

这些是探索性证据：支持与冲突可以同时出现在同一个点上，分母包含未定或遮挡样本，目标视图数量不一致，部分目标只有4条预留记录。不能把支持比例简单当正确率，也不能比较不同样本集合的谱就宣布精度提升。

因此后续软件应同时展示局部约束、双向覆盖、相同源点敏感性和原深度冲突，再由用户确认对应关系；不按单一残差或条件数自动接受。4→3与7→6的共同源点比值分别约0.047%和0.028%，提示额外弱方向，但本轮没有推断实际相机运动或补扫方向。
